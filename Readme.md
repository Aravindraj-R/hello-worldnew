# hello-worldnew

This is a test repository for demonstrating GitHub functionality, particularly focused on issue management and automation.

## Features

### Issue Templates
This repository includes the following issue templates:
- **Bug Report**: For reporting bugs and issues
- **Feature Request**: For suggesting new features or improvements
- **Test Issue**: For creating test issues to verify repository configurations

### Automated Workflows
The repository has automated workflows that:
- Welcome new issues with a customized message
- Automatically label test issues when they contain `[TEST]` in the title
- Verify that issues are properly formatted and workflows trigger correctly

## Testing GitHub Functionality

To test the issue functionality:
1. Navigate to the [Issues tab](https://github.com/Aravindraj-R/hello-worldnew/issues)
2. Click "New Issue"
3. Select one of the available templates
4. Fill in the template fields
5. Submit the issue
6. Observe the automated workflow response

### Expected Behavior
When you create a new issue:
- The issue should display with proper formatting
- The welcome workflow should trigger within a few seconds
- A welcome comment should be added automatically
- For test issues, the comment will confirm that automation is working correctly

## Purpose
This repository serves as a testing ground for:
- Issue templates and configurations
- GitHub Actions workflows
- Repository automation features
- Integration testing with GitHub's API

Feel free to create test issues to explore these features!
